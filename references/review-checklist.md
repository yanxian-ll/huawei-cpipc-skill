# 华为杯论文终稿审查清单

用于 Draft/Rewrite/Audit 后的最后一轮审查。先查硬性违规，再查逻辑，再查写作。

---

# A. BLOCKER：出现即优先处理

## A1. 匿名与模板

- [ ] 使用当年官方模板。
- [ ] 首页封皮保留完整，官方要求的 logo 未被替换。
- [ ] 第二页起没有学校、学院、实验室、导师、队员姓名、队伍编号、邮箱、个人主页等身份信息。
- [ ] 没有页眉。
- [ ] 摘要页起连续编号，页码位置符合官方要求。

## A2. 文件与提交

- [ ] PDF 文件名符合当年规则。
- [ ] 论文为最终 PDF，而不是 Word/LaTeX 源文件或压缩包。
- [ ] 在提交 MD5 前完成全部修改。
- [ ] MD5 提交后不再重新导出、保存或修改 PDF。
- [ ] 正文中声称上传的附件与实际附件一致。

## A3. 引用与学术规范

- [ ] 没有虚构文献、作者、DOI、网址、数据来源。
- [ ] 所有外部模型、算法、公式和公开资料有真实可查来源或清晰推导。
- [ ] 引用程序注明来源。
- [ ] 书籍引用包含页码（按 2026 规则）。
- [ ] 参考文献顺序与正文首次引用顺序一致。

## A4. AI 使用

- [ ] 团队理解并人工核验 AI 辅助产生的内容。
- [ ] 最终文字已由团队用自身语言确认和定稿。
- [ ] AI 辅助数据分析时按当年规则进行必要标注。
- [ ] AI 辅助代码时在程序前按当年规则标注工具名称、版本/型号、开发机构/公司、版本日期。
- [ ] 若赛题要求 AI 输入和输出后处理记录，材料齐全且真实。

---

# B. 论文主线检查

把每个问题填成以下链条：

`题目要求 -> 问题分析 -> 假设/数据 -> 模型 -> 求解 -> 结果 -> 检验 -> 最终回答`

逐问确认：

- [ ] 每个子问题在问题重述中被明确写出。
- [ ] 每个子问题在问题分析中有对应建模路线。
- [ ] 每个子问题都有实际模型或方法，而不是只有文字讨论。
- [ ] 每个子问题都有明确输出结果。
- [ ] 每个关键结果都能追溯到公式、算法、表格、图或计算文件。
- [ ] 结论逐问回答，没有漏问。

若一问无法连成完整链条，标记为 `MAJOR`。

---

# C. 摘要检查

2026 官方要求摘要包括建模思路、主要方法、模型、结果与结论、创新点和关键词。

检查：

- [ ] 第一段很快进入题目核心，而不是大段宏观背景。
- [ ] 每个主要子问题至少出现“方法/模型 + 关键结果”。
- [ ] 有具体数字时直接给数字，不用“效果较好”代替。
- [ ] 摘要中的模型名称与正文完全一致。
- [ ] 摘要中的数值与正文、结论完全一致。
- [ ] 摘要中声明的创新在正文中确实存在。
- [ ] 摘要不包含正文没有验证的新结论。
- [ ] 摘要不是“首先、其次、然后、最后”的纯流程描述。
- [ ] 篇幅符合当年官方要求。

### 摘要句子角色快速检查

理想角色以 `T M R E V C` 为主。

如果连续 3 句都是 `B`，背景过长。

如果没有 `R/E`，摘要缺结果。

如果只有 `M` 没有结果，像“方法目录”。

---

# D. 引言 / 问题背景检查

- [ ] 说明了问题为何值得建模，而不是行业口号。
- [ ] 背景事实与本题直接相关。
- [ ] 若提到已有方法，有真实引用。
- [ ] 明确指出本题的具体难点或建模缺口。
- [ ] 简述本文工作，但不详细复制摘要结果。
- [ ] 没有长篇数学推导。
- [ ] 没有大段最终数值结果。

若删除一段引言后完全不影响读者理解问题与研究动机，该段多半可以删。

---

# E. 问题重述检查

- [ ] 用自己的语言压缩题意，没有大段复制原题。
- [ ] 已知条件和输出目标清楚。
- [ ] 一问一条或一小段，便于评委对应。
- [ ] 没有提前出现最终结果。
- [ ] 没有把模型方法写成题目要求。

---

# F. 问题分析检查

对每一问确认：

- [ ] 说清“本质上是什么问题”。
- [ ] 说明核心变量和主要影响因素。
- [ ] 说明为什么选择该模型/方法。
- [ ] 说明子问题之间的依赖关系。
- [ ] 有建模路线，而不是只有模型名。
- [ ] 没有提前报告最终结果。

问题分析应回答“为什么这样做”，模型建立应回答“具体建立了什么”。

---

# G. 假设检查

- [ ] 每条假设会实际影响公式、变量或求解过程。
- [ ] 假设与题目条件不冲突。
- [ ] 有必要时给出合理性依据。
- [ ] 没有为了“凑数量”写无关常识假设。
- [ ] 强假设的适用范围在局限性部分有说明。

对每条假设问：**如果删掉这条，模型哪里会变？** 若答案是“哪里都不变”，考虑删除。

---

# H. 符号检查

- [ ] 同一符号全文只有一个含义。
- [ ] 同一量没有在不同章节换符号。
- [ ] 单位统一。
- [ ] 下标、集合、向量与标量记法一致。
- [ ] 公式中首次出现的重要符号均有定义。

---

# I. 数据与预处理检查

- [ ] 数据来源明确。
- [ ] 外部数据可追溯。
- [ ] 缺失值、异常值、重复值处理规则明确。
- [ ] 删除数据有理由。
- [ ] 标准化/归一化/插值公式或方法明确。
- [ ] 特征构造有定义和解释。
- [ ] 处理后样本量与统计信息自洽。

避免只写“对数据进行预处理”。

---

# J. 模型建立检查

每个模型检查：

- [ ] 建模目标明确。
- [ ] 模型选择理由与题目特征相关。
- [ ] 决策变量、状态变量、参数、索引明确。
- [ ] 目标函数每一项有现实含义。
- [ ] 约束条件逐条对应现实限制。
- [ ] 关键公式有推导或真实来源。
- [ ] 关键公式后有解释，不是“公式墙”。
- [ ] 参数来源或估计方法明确。
- [ ] 模型可以由团队提供的数据和代码实际求解。

高风险句：

> “根据相关理论，可得如下公式……”

如果后面没有来源或推导，标记 `MAJOR`。

---

# K. 算法 / 求解检查

- [ ] 说清模型输入和算法输出。
- [ ] 说明为什么需要该算法。
- [ ] 步骤可以复现。
- [ ] 关键超参数写明。
- [ ] 停止条件写明。
- [ ] 随机算法有随机种子或重复实验说明（若重要）。
- [ ] “Python/MATLAB 求解”没有被错误当作建模方法本身。

---

# L. 结果与分析检查

每个核心表/图检查：

- [ ] 正文先或后明确写出最重要的发现。
- [ ] 不只写“如图所示”。
- [ ] 报告与题目直接相关的数值。
- [ ] 对比有基准对象。
- [ ] 百分比变化计算正确。
- [ ] 小数精度有意义。
- [ ] 将“计算事实”和“机制解释”区分开。
- [ ] 没有把相关性直接写成因果性。
- [ ] 每个结果最终回扣某个题目要求。

---

# M. 验证 / 误差 / 敏感性检查

## 验证

- [ ] 检验对象明确。
- [ ] 指标明确。
- [ ] 测试集/交叉验证/已知规律等方式明确。
- [ ] 报告实际数值。

## 误差

- [ ] 有明确误差定义。
- [ ] 报误差大小或分布。
- [ ] 分析主要误差来源。
- [ ] 说明误差是否改变核心结论。

## 敏感性

- [ ] 扰动对象有理由。
- [ ] 扰动范围明确。
- [ ] 结果变化量可量化。
- [ ] 最终说明核心结论是否稳定。

不要用“波动较小，因此模型稳定”代替数据。

---

# N. 模型评价 / 改进检查

- [ ] 优点对应真实模型特征或实验，不是自夸。
- [ ] 局限具体到假设、数据、算法或应用范围。
- [ ] 改进建议能对应局限。
- [ ] 推广说明需要满足的前提，而不是“可广泛应用”。

---

# O. 结论检查

- [ ] 开头直接总结解决了什么。
- [ ] 每个子问题都有直接答案。
- [ ] 关键答案有数字或明确方案。
- [ ] 重要验证结论被概括。
- [ ] 没有重新展开算法细节。
- [ ] 没有引入正文不存在的新实验、新模型、新数字。
- [ ] 不与摘要逐句重复。
- [ ] 必要时说明适用范围或局限。

### 结论句子角色快速检查

应以 `R E V I L` 为主。

若大量是 `M`，说明在重复方法章节。

若大量是 `B`，说明结论没有收束。

---

# P. 摘要 / 引言 / 问题分析 / 结论去重检查

拿同一段信息检查四次：

- 摘要：只保留压缩后的“方法 + 结果”。
- 引言：只保留“为什么值得做 + 本文做什么”。
- 问题分析：只保留“为什么这样拆 + 为什么这样建模”。
- 结论：只保留“最终答案 + 可靠性 + 边界”。

如果四处出现几乎相同的连续句子，重新分工。

---

| 问题二模型名 | | | | |
| 问题二核心数值 | | | | |
| 关键指标定义 | | | | |
| 创新点 | | | | |

任何不一致都应在提交前修复。

---

# R. 最后 10 分钟检查

- [ ] 搜索全文学校名、队员名、导师名、队伍编号。
- [ ] 搜索 `TODO`、`待补`、`XXX`、`??`、高亮标记。
- [ ] 检查图表编号是否连续。
- [ ] 检查所有图表在正文中被引用。
- [ ] 检查所有公式编号引用存在。
- [ ] 检查参考文献正文引用是否都存在。
- [ ] 检查摘要、正文、结论关键数字一致。
- [ ] 检查附件文件名和正文附件说明一致。
- [ ] 最后导出 PDF 后逐页快速查看乱码、跨页、公式、图表。
- [ ] 确认无误后再生成并提交 MD5。
